# Crafty
A Royal Holloway Final Year Project.

You find yourself falling into a world of 2D people, their craftsman is gone and you are their only hope. Collect items, run from robbers, and craft new items to help the residents of this island. Maybe they can help you find a way back to your 3D world.

No generatve AI was used in this project.

## Controls
Movement: WASD or ←↑↓→
Jump: SPACE
Inventory: I
Crafting: C
Pause: ESC


## Running the game
You can find links to download the game at https://jifter.itch.io/crafty

Windows:

Download  the CraftyWindows zip file and unzip on your device.

Run the CraftyWindows.exe file



Linux: 

Download the CraftyLinux zip file and unzip on your device.

Ensure the CraftyLinux.x84_62 file has executable permissions on your device.

Run the CraftyLinux.x84_62 file.
